# Adaptive Learning Control for Robust Trajectory Tracking in Robotic Systems

## 📌 Project Overview

This BTech Mini Project presents an adaptive learning control strategy for trajectory tracking in robotic systems subject to environmental perturbations. Inspired by human motor learning principles, the proposed controller adapts over successive trials using feedback from previous errors.

## 🧠 Key Features

* **Iterative Learning Control (ILC)**: Learns from past errors to refine control inputs.
* **Feedforward Control**: Uses an internal model to proactively compensate for system dynamics.
* **Predictive Modeling**: Incorporates a sensory prediction mechanism for anticipatory correction.
* **Combined Control Strategy**: Blends ILC and feedforward components to ensure robust and adaptive control.

## 🔬 Simulation Details

* The controller was tested on a simulated robotic system.
* Target trajectories included: Square, Ellipse, and Hexagon.
* Demonstrated improved tracking performance and adaptability under perturbations.
